# Proyecto-Semestral-Modelos-I

Proyecto Integrador de **Modelos y Simulación de Sistemas I**, desarrollado durante el semestre en tres entregas que cubren cuatro fases:

1. **Entrega 1:** Fase 1, modelo predictivo.
2. **Entrega 2:** Fase 2, scripts y Docker.
3. **Entrega 3:** Fases 3 y 4, API REST y monitoreo básico.

El problema aprobado por el equipo es la regresión del precio de autos usados con datos de la competencia [Regression of Used Car Prices (Kaggle Playground Series S4E9)](https://www.kaggle.com/competitions/playground-series-s4e9). La documentación y artefactos de la primera fase están en [`fase-1/README.md`](fase-1/README.md).

El conjunto de Playground Series S4E9 es sintético: según la [pestaña Data de Kaggle](https://www.kaggle.com/competitions/playground-series-s4e9/data), sus datos de entrenamiento y prueba fueron generados por un modelo de aprendizaje profundo entrenado con el [Used Car Price Prediction Dataset](https://www.kaggle.com/datasets/taeefnajib/used-car-price-prediction-dataset). Sus 188.533 filas no son observaciones directas del mercado, por lo que sus resultados no bastan para generalizar al mercado real ni para justificar por sí solos un uso comercial.
